# Security

Report a vulnerability privately through [GitHub's private vulnerability reporting](https://github.com/priemskiyyy/pulse/security/advisories/new), not in a public issue. Include the Pulse version, the adapter and runtime involved, and the smallest example that shows the problem, with tokens and personal data removed.

Fixes go into the latest release as a new patch version with its changelog entry. The advisory is published once that release is on npm.

Lifecycle signals are observations, not security claims. Never use a foreground state or an away time to authorize access, unlock protected content or expire a session; see [what Pulse is not](README.md#what-pulse-is-not).
